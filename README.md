# OpenNetSim

**OpenNetSim** — открытый (GPL) симулятор сетей для обучения,
сочетающий в себе простоту Cisco Packet Tracer и гибкость запуска
реальных образов устройств через QEMU.

## Описание

OpenNetSim позволяет студентам, начинающим сетевым инженерам и
преподавателям перетащить на рабочее поле устройства (роутеры,
коммутаторы), соединить их линками и управлять ими через привычные
интерфейсы — от WinBox до CLI-терминала.

### Ключевые особенности

- **Не привязан к одному производителю** — поддерживает MikroTik,
  Huawei, Dell и другие (по мере добавления образов).
- **Лёгкий старт** — базовая симуляция работает без тяжёлых ВМ;
  эмуляция реальных образов (например, MikroTik CHR) — опционально.
- **Прозрачный доступ** — проброс портов выполняется автоматически
  только на `127.0.0.1`, пользователь не видит портов и туннелей.
- **Открытый исходный код** — лицензия GPL v3.
- **Расширяемость** — добавление новых устройств через плагины и
  конфиги без переписывания ядра.

### Архитектура

Приложение состоит из четырёх слоёв:

| Слой                  | Ответственность                                      |
|-----------------------|------------------------------------------------------|
| **GUI**               | Рабочее поле, drag-and-drop, визуализация линков     |
| **Менеджер (manager)**| Запуск/остановка QEMU, управление пробросом портов  |
| **Ядро (core)**       | Состояние сети, расчёт прохождения пакетов          |
| **CLI**               | Эмуляция командного интерфейса (RouterOS, VRP)      |

Между слоями — JSON API для топологии и события для обновления UI.

## Быстрый старт

```bash
git clone https://github.com/yourname/OpenNetSim.git
cd OpenNetSim
pip install -r requirements.txt
python main.py
```

> **Требования:** Python ≥ 3.10, PyQt6, QEMU (системная установка).
